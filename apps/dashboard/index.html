WALLET MODEL

Two modes. Neither gives the website your key.

01

Injected wallet

For the public dashboard. MetaMask, Rabby and other injected EVM wallets keep signing in the wallet extension.

02

Encrypted local fleet

For CLI, VPS and automation. Keys are encrypted with scrypt + AES-256-GCM in a local file. The dashboard HTTP API cannot upload them.

npm run cli -- vault create wallets.enc.json
